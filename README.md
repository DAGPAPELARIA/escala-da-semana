# Escala da semana (terça a domingo)

Página única com a escala da equipe, montada a partir da folha manuscrita de 16/11/2026.

- `index.html`: versão interativa. Toque em um nome para ver todos os dias dele. Funciona no computador e no celular (em tela pequena vira uma coluna, com a barra de nomes fixa no topo).
- `escala-da-semana.pdf`: a mesma escala em uma página, para imprimir ou enviar.

Observações da folha:

- Na sexta, o nome depois da Rafaela foi lido como "Roje"; a grafia precisa ser confirmada.
- "Oroch" foi entendido como veículo.
- A observação "todos os dias" no domingo aparece cortada na folha original.
